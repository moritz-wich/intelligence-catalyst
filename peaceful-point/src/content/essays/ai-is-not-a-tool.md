# AI Is Not a Tool. It Is a Catalyst.

This is the beginning of Intelligence Catalyst.

AI is usually described as a tool: something that helps us
write, code, analyze, design or communicate faster.

But perhaps this description misses the more important change.

A tool makes existing work more efficient.

A catalyst can make entirely new things possible.

That is the question this blog will explore.
